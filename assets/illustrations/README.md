# 旅あるきの表示用イラスト

2026-10-20の利用者指示・添付②（大使館スタンプラリーで使用した3人の元画像）を基準に、imagegenの組み込みツールで作成しました。利用者がこの改修での使用を指示した画像以外の、第三者サイトの写真・キャラクター素材は使用していません。添付①は雰囲気と構成の参考だけに使い、スクリーンショットは画面へ貼り付けていません。

| 素材 | 用途 |
| --- | --- |
| travelers.png | 元画像の左の男性、中央の人物、右の女性の服装・髪・表情・画風・ポーズを維持した透過素材。等幅3列をCSSで切り分け、配置だけを変更 |
| hokkaido.png | 函館の五稜郭・海・函館山から見た夜景のイメージと、札幌の北海道大学の銀杏並木。人物・文字・日付・訪問順を含まない独立背景 |
| generic.png | 地域や旅行先を特定しない湖・丘・木々の汎用背景。人物・文字・日付・訪問順なし |

背景とキャラクターは別レイヤーで合成し、文字・ボタン・予定・交通/宿泊はHTMLから表示します。背景は地理・経路の正確な案内ではありません。実際の旅程とは独立した風景イメージです。元の添付画像や利用者のiPhoneスクリーンショットは公開ファイルへコピーしていません。

背景選択とパスはsrc/brand.jsの表示用設定に集約しています。旅行名が「北海道」を含むときだけ北海道の風景、それ以外と未選択時は汎用背景にします。旅行データへ背景情報を書き込まず、保存形式は変えません。

## 生成プロンプトの要点

組み込みimage_genを使用（API/CLIは使用せず）。入力は利用者提供の添付②、1枚。出力はそれぞれ1536×1024px。

1. **background-extraction / identity-preserve**：元画像の下部の3人だけを抽出。顔・髪・服・配色・線・指差すポーズを維持。男性は黒い肩掛けバッグと青い服、中央は灰色パーカーと緑のズボン、女性は灰色上着と青いズボン。全身と靴を残し、共通の足元ライン、等幅3列に配置。背景・銅像・看板・文字・影を除き、透明背景。別人物・追加人物・UIは作らない。
2. **illustration-story / Hokkaido background**：参照の親しみやすい手描きの黒輪郭・平塗り・淡い紙感を維持。左は五角形の五稜郭と堀、函館の港と夜景・海。右は黄金色の銀杏並木と淡い青空。下部は別レイヤーの人物を置ける構図。人物・文字・数字・ホテル・航空便・経路・順序・UI・透かしは禁止。
3. **illustration-story / generic background**：地域を特定しない緑の丘、青い湖、丸い木々、低い石垣、砂色の前景と青空。明るい旅行ノートの手描き調。下部に人物を別レイヤーで置ける構図。特定のランドマーク・人物・文字・数字・日付・経路・UI・透かしは禁止。

生成後に元画像と照合し、特徴・服装・3人の構成と、背景に日程情報がないことを目視確認しました。[使用プロンプト全文](prompts.md)も記録しています。イラストの差し替え時も名称/データと独立させ、この記録とService Workerのhashを更新してください。
