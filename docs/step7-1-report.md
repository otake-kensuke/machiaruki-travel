## 文字とレイアウト

標準のブラウザ文字サイズ16px時の値。ルートは`100%`とし、相対単位で文字の拡大に追従します。

| 対象 | サイズ・太さ |
| --- | --- |
| 本文・メモ・住所 | 16px |
| 予定名・訪問先名・交通/宿泊施設名 | 19px、太字 |
| 日付・時刻・交通/宿泊の日時 | 18px、主要な時刻は太字 |
| 日別の日付見出し | 22px、太字 |
| 補足・座標・バッジ・日付タブのDAY表示 | 原則15px |
| ヘッダー補足・バージョン | 14px |
| 主要操作ボタン | 17px、太字、最小高さ48px/幅44px |
| 下部ナビゲーション | 15px、太字、最小高さ64px |

本文色`#152e31`と基本の緑・空色・クリーム背景を維持。補足色は`#43585d`へ濃くし、選択タブのDAY表示を`#315c46`、中立バッジを`#4d5748`に変更しました。画像キャプションは文字の下を不透明な明るい面にしています。表示文字を実ブラウザで走査し、通常4.5:1、大文字3:1の基準を確認しました。これは対象画面の文字と背景の確認であり、WCAG全項目への適合認証ではありません。

狭い幅や大きい文字では、カード見出し・ボタン・時刻欄・入力欄が折り返します。画面の倍率を固定する指定や文字拡大を禁止する指定は追加していません。下部の固定ナビゲーション用の余白も相対単位にしています。

## 日付タブ

日付の生成・並び順・選択と予定表示の連動はそのままです。再描画前に同じ旅行の横スクロール位置を取得し、描画後に選択タブの中心とスクロール領域の中心の差を求めます。移動先は`0`から`scrollWidth - clientWidth`までに制限します。

画面を開いた直後は即座に選択タブを表示し、日付切替はブラウザ標準のスムーズスクロールを使います。`prefers-reduced-motion: reduce`の場合は即座に移動します。再び同じタブを押した場合も中央寄せします。`scrollIntoView()`は使わず、日付領域の`scrollTo({ left })`のみを操作するため、中央寄せが画面全体を縦に移動させません。手動の横スクロールを強制的に戻す処理もありません。

初回ホームはURLに画面名・旅行IDがない場合があります。文字拡大で日付選択欄が画面下に移動した際の回帰確認で、最初の日付選択だけ先頭へ戻る問題が見つかりました。表示中の旅行を照合して、その場合も既存の位置保持を適用しています。旅行や日程の選択ルール、保存データには変更がありません。
