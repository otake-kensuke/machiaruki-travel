## テスト結果

- Node.js：13/13成功。
- Edge Chromium：19/19成功。
- 初回起動ではサンプルもactiveレコードも未作成。明示保存後は再読込・タブ再オープン・ブラウザプロセス再起動で全データ一致。
- 同一ID・不正参照を拒否。異なるデータの2タブ並行追加は双方を保持。同一データの並行追加は片方だけ成功。
- トランザクション中断・容量不足を模した書込失敗で既存データを保持。確認ダイアログとエラーが残り、再試行可能。
- 未知の保存形式を削除・初期化せずエラー表示。IndexedDB利用不可時に保存成功を誤表示しない。
- HTML風の名称を文字列として表示。サブパスでの読込・保存・遷移を確認。
- 1365pxのPC画面、390px・320pxの3画面を確認。横スクロールなし。PCホームと390pxの3画面はPNGを目視確認。
- srcのJavaScript構文確認成功。テスト対象ページの例外・コンソールエラーなし。
