# Step 4 実装報告

ベース：2f4d020 / 対象：訪問登録編集・単発GPS・Googleマップ外部リンク

## 実装内容

予定カードの「訪問を記録」は施設名・住所を初期入力し、planIdで関連付けます。「＋ 訪問記録を追加」は施設名を手入力し、planId=nullで保存します。両方とも開始時の現在時刻を初期値にし、入力→内容確認→保存の順です。GPS地点・精度・取得日時を保持し、予定地点を実績へコピーしません。

GPSはgetCurrentPositionの単発取得です。起動・閲覧・既存記録の編集では取得せず、開始と明示再取得時のみ呼びます。拒否・失敗・タイムアウトでも座標なしで記録できます。GPS待ちでも入力・確認を続けられます。確認時に候補を固定し、確認後/閉じた後/再取得後の古い結果は無視します。

予定と訪問時刻を明示的に区別し、複数訪問をすべて表示します。訪問日時・施設名・住所・メモを編集できます。編集時はID・createdAt・予定参照・元のGPS情報を保持します。予定が削除済みでも履歴が残ります。実際の訪問日は旅程外も扱い、日付切替と振り返りに表示します。

GoogleマップはMaps URLsの外部リンクです。保存座標があればその位置、なければ訪問側の施設名・住所で検索します。クリック前の地図通信、APIキー、有料API、逆ジオコーディングはありません。

## データ保護

DB名・構造バージョン1・schemaVersion 1.0・6コレクションを維持し、既存データを初期化しません。訪問の任意addressは従来記録では省略可能で、予定から独立した検索用文字列です。保存は既存方式と同じreadwriteトランザクションで最新値を検査し、完了後だけ成功表示します。別タブで同じ訪問が更新済みなら上書きを拒否し、入力・確認候補を保持します。別の予定・訪問や並行新規追加は取りこぼしません。
