# Step 7「旅あるき」UI/UX改修報告

実施日：2026年10月20日（日本時間）。基準：公開版 `5134eaa`。

実際の北海道旅行は計画立案中です。既存サンプルは架空データのまま変更せず、旅行日程・訪問先・ホテル・交通便をデザインへ固定していません。

## デザインと操作の変更

- 暫定表示名を「旅あるき」へ統一。ヘッダー・画面タイトル・PWA/Apple表示名・共有タイトル・データエラーの名称・キャッシュ再準備画面をそろえました。プロジェクト名は街歩きラボ、URL/repository/DB/appIdは従来のままです。
- 表示名・PWA色・背景パスはsrc/brand.jsへ集約。名称変更後はupdate-brand、update-shellの順に実行して静的HTML/PWA/workerへ反映できます。アイコンに文字は埋め込んでいません。
- 明るい空色、クリーム、深緑、黄/コーラルのアクセントと、読みやすいカード・ボタンに統一。入力欄は16px、主要ボタンは48px以上、既存の3画面ナビゲーションを維持しました。iPhone 16相当の393×852を優先し、320/430px・PCでも確認しています。
- ホームを、イラスト→旅行名/期間→件数→日別予定→コンパクトな全体日程→交通/宿泊→データ管理のダッシュボードへ変更。日程一覧の上部に背景イラストは追加していません。
- ホームの日付切替でスクロール位置を保持します。旅行前は最初の登録日、旅行中は旅行タイムゾーンの今日、旅行後は最後の登録日を案内。登録のない日を作ったり、別の日を今日として表示したりしません。
- 日数・件数・時刻・施設名・交通/宿泊は保存データから表示。交通/宿泊は展開できる登録情報にし、未登録時も案内を表示します。「登録」を予約済みとは表現しません。
- バックアップ・復元・旅程取込はホーム下部のデータ管理に維持。オフラインは各画面の下部に準備状態と再確認ボタンを常設し、詳細を折りたたみました。実際の更新待機/失敗時は詳細を自動で開きます。初回準備の短い待機状態を新版更新と誤案内しないよう区別しました。
- 予定/記録と振り返りは共通色・文字・アイコン・ボタンを中心に変更し、保存操作・GPSの手順は維持しています。

## 画像素材

利用者添付②の3人を基準にimagegenスキルの組み込みimage_genで透過素材を作成しました。元の左男性の青い服と黒バッグ、中央の灰色パーカーと緑のズボン、右女性の灰色上着と青いズボン・髪・表情・手描きタッチを照合しました。函館側に左右の2人、札幌側に中央の人物をCSSで配置します。

背景2種と人物は独立したPNGです。背景は写真調ではなく手描き調で、文字・日付・ホテル・交通時刻・訪問順は含みません。HTMLのボタンや旅行情報を画像化していません。北海道の旅行名なら函館の五稜郭/海/夜景と札幌の銀杏並木、それ以外は地域を特定しない丘と湖の風景を使います。背景の選択は表示専用で、保存データに背景設定を追加しません。

素材はすべてassets/illustrations/へ保存しました。[出典と役割](../assets/illustrations/README.md)、[使用プロンプト全文](../assets/illustrations/prompts.md)を記録しています。利用者が今回の使用を指示した添付画像以外の第三者素材は使用していません。元画像や参考モックを全面スクリーンショットとして貼り付けていません。作業フォルダーにあった利用者のiPhone画像は編集・公開せず、除外対象にしました。

## データ・既存機能への影響

DB名machiaruki-travel、DBバージョン1、workspaceストア、全6配列、schemaVersion 1.0、appId、ID、createdAt/updatedAt、JSON名の接頭辞は維持しました。storage.js/model.js/予定・訪問の更新ロジックと同梱サンプルJSONは変更していません。validation.jsは表示するアプリ名のみ変更しました。

ホームの導出は純粋な読み取り処理です。表示・日付切替・背景変更で保存APIを呼びません。GPSは既存の訪問記録時だけです。外部API/CDN/DB/自動アップロードを追加していません。Service Workerは40アセットを内容hashで検証し、従来の待機更新を維持しています。追加したSHELL.appNameはキャッシュ管理情報であり、旅行JSONのスキーマ変更ではありません。
