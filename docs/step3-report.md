# Step 3 実装報告

対象：旅程JSON取込、予定の追加・編集・削除 / 2026年10月17日

## 実装

旅行ホームからJSONファイルを選択し、旅行名・期間・日別/予定/交通/宿泊の件数を表示します。確認ボタンを押した場合のみ端末に追加します。kindはitinerary限定、最大2 MiB。JSON構文、スキーマ、型、ID重複、日付、座標、参照整合性を検証し、不正な入力や既存IDとの衝突では保存を中止します。自動マージや全件置換はありません。プレビュー後に別タブで同じIDが追加された場合も、保存時の再検証で拒否します。

今日の予定画面に追加・編集・削除操作を実装しました。編集ではIDとcreatedAtを維持し、updatedAtを更新します。旅行タイムゾーンの日付・時刻、施設名・分類・住所・メモを入力できます。時刻未定を許容し、入力先の日別データがなければ同時に作成します。

削除には確認画面があり、すべての予定を削除済みとして内部に保持します。訪問記録の全内容とplanId参照は変更しません。同じ予定が別タブで変更された場合は上書きせず、入力を残して競合を表示します。保存は最新データを読むreadwriteトランザクション内で実施し、完了後にだけ成功を表示します。
